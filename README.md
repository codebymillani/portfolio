# Portfolio

This is my personal portfolio site. I'm a Computer Science student at UCF moving toward UX Research and Product Design, and this is where I'm putting that work together instead of just describing it on a resume.

I built it from scratch with plain HTML, CSS, and JavaScript instead of a template or framework, working through the code and content with Claude (Anthropic's AI).

## Live site

https://codebymillani.github.io/portfolio/

## Pages

- index.html: home page with a quick intro and my areas of focus
- about.html: more about my background and how I ended up here
- projects.html: case studies and past projects, filterable by category
- skills.html: what I actually know and use
- contact.html: how to reach me

## Built with

- HTML5
- CSS3, custom, no framework
- Vanilla JavaScript
- Font Awesome for icons

## Running it locally

```bash
git clone https://github.com/codebymillani/portfolio.git
cd portfolio
```

Then just open index.html in a browser. No build step.
